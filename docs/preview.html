🌱 Beginner guide — read this and you are a professional

You will know more than most interview candidates after these 7 ideas. Each idea is one paragraph + one command. Run them in order.

1
The log, not the database. Five servers each keep a numbered list of commands. Same list + same order ⇒ same answer, always. Run python3 experiments/exp_overlap.py first? No — start with order: two servers run set x=1; add 4 in opposite orders and get 5 vs 1. That is why order is everything.
2
Majority = truth. With 5 servers, 3 is a majority. Any two groups of 3 share a server, so no two majorities can disagree unknowingly. exp_overlap.py checks all 45 pairs. Groups of 2 fail 15/45 — that is why Raft never commits with 2/5.
3
One boss: the leader. Clients talk only to the leader; followers copy. Heartbeats every 50ms say “I am alive”. Miss 150–300ms of them and a follower runs for election. exp_election.py boots a leader in ~190ms.
4
Split votes need jitter. Three followers timing out together each get ~1 vote — nobody wins. Random timers break the tie. Zero jitter: 200/200 stuck. 150ms jitter: median ~206ms, worst ~516ms. Randomness fixes the tail, not just the average.
5
Copy, check, commit. Leader sends entries + “what came before”. Followers reject mismatches; leader steps back and retries. On 3/5 copies the entry is committed (~20ms = one round trip). One dead server changes nothing. exp_replication.py
6
Two safety rules. (1) Vote only for logs at least as new as yours — stops empty servers becoming boss. (2) Count only your own-term entries toward commit — old entries commit indirectly. Remove rule 1 and data loss is instant (exp_safety.py). Rule 2 needs the exact crash sequence: random tests miss it, proofs catch it.
7
The chaos monkey. Dice kill servers, cut networks, drop 5% of messages — while two alarms watch: one leader per term, one command per slot. 100 runs × 7,982 kills ⇒ zero alarms. Then the same code runs on real sockets (exp_live.py, failover ~200ms). exp_chaos_1000.py

❓ FAQ + troubleshooting

Do I need to install anything?

No. Python 3.10+ only. Docker optional for identical reruns.

Why 5 servers, not 3 or 7?

3 tolerates 1, 5 tolerates 2, 7 tolerates 3. Even sizes waste a server (4 needs 3 — same as 3). Odd sizes only.

Can two leaders exist at once?

Yes, briefly, across terms during partitions. Only a majority can commit, so safety holds. The demo shows it.

No leader for 5 seconds — bug?

With 2/5 alive, that is correct. A minority cannot tell death from partition, so it stalls rather than risk split-brain.
